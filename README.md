# CLSU GWA Calculator

React + Vite + Tailwind CSS (black & blue theme).

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. In Vercel: **Add New → Project**, import the repo.
3. Vercel auto-detects Vite (build: `npm run build`, output: `dist`). Click **Deploy**.

Or with the CLI: `npm i -g vercel && vercel --prod`.
